# Heart Health Analysis

## Project Overview

An Exploratory Data Analysis and introductory predictive analysis project focused on understanding factors associated with heart disease.

## Objectives
Explore patient characteristics and heart-health indicators.
Identify relationships between health features and heart disease.
Examine relationships among important clinical features.
Examine relationships among age and sex on heart health.


## Dataset

Heart disease dataset containing demographic, clinical, and diagnostic attributes, including age, sex, chest pain type,
cholesterol, blood pressure, ECG-related variables, and target outcome.

## Analysis Performed
Data inspection and preprocessing.
Missing-value and data-quality checks.
Descriptive statistical analysis.
Univariate and bivariate analysis.
Feature relationship analysis.
Chest pain and ECG analysis.
Correlation analysis.
Visualizations

## Tools & Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Kaggle Notebook

## Key Skills

Healthcare Data Analysis, Data Cleaning, Statistical Analysis, Feature Analysis, and Classification.
